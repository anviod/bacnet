## 1. 概述与前置条件

本指南面向使用 `github.com/anviod/bacnet` 作为 BACnet/IP 客户端库的开发者，提供从**远程主机**对目标 BACnet 设备进行添加、扫描、读取和写入的完整实施方案。

### 1.1 适用场景

- 采集端与 BACnet 设备不在同一台机器上（跨主机/跨网段）
- 目标设备已在运行
- 需要可靠的点位数据采集和写入能力

### 1.2 依赖

| 依赖 | 说明 |
|------|------|
| Go 1.18+ | 编译环境 |
| `github.com/anviod/bacnet` | BACnet 协议栈 |
| UDP 网络可达 | 采集端与目标设备之间 UDP 端口可达 |

> **交叉编译提示**：部署到 Linux ARM 网关时使用静态编译：
> ```bash
> CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go build -o scanner ./cmd/scanner
> ```

## 2. 设备添加

添加一台 BACnet 设备需要三个关键要素：**Device ID + IP + Port**。现场工程以手动添加为主；当端口未知时，用 WhoIs 单播和广播组合发现作为补充。

### 2.1 手动添加（主要方式）

已知 Device ID、IP、Port 时，直接用 `IPPortToAddress` 构造设备并验证可达性。这是现场工程最常用的方式。

```go
import (
    "net"
    "github.com/anviod/bacnet/btypes"
    "github.com/anviod/bacnet/datalink"
)

// 已知三要素：Device ID=2228316, IP=192.168.3.115, Port=47808
targetIP := net.ParseIP("192.168.3.115")
addr := datalink.IPPortToAddress(targetIP, 47808)

dev := btypes.Device{
    DeviceID: 2228316,
    Addr:     *addr,
    Ip:       "192.168.3.115",
    Port:     47808,
    MaxApdu:  btypes.MaxAPDU,
    ID: btypes.ObjectID{
        Type:     btypes.DeviceType,
        Instance: btypes.ObjectInstance(2228316),
    },
}

// 验证可达性：读取 Object_Name
rp, err := client.ReadPropertyWithTimeout(dev, btypes.PropertyData{
    Object: btypes.Object{
        ID: btypes.ObjectID{
            Type:     btypes.DeviceType,
            Instance: btypes.ObjectInstance(2228316),
        },
        Properties: []btypes.Property{{
            Type: btypes.PropObjectName, ArrayIndex: btypes.ArrayAll,
        }},
    },
}, 8*time.Second)

if err != nil {
    log.Printf("设备 %d 不可达: %v", 2228316, err)
} else {
    log.Printf("✓ Device %d = %v", 2228316, rp.Object.Properties[0].Data)
}
```

**批量添加多台设备**：

```go
type DeviceTarget struct {
    DeviceID int
    Port     int
}

targets := []DeviceTarget{
    {DeviceID: 1234, Port: 47810},
    {DeviceID: 2228316, Port: 47808},
    {DeviceID: 2228317, Port: 60835},
    {DeviceID: 2228318, Port: 50906},
}

targetIP := net.ParseIP("192.168.3.115")
devices := make(map[int]btypes.Device)

for _, t := range targets {
    addr := datalink.IPPortToAddress(targetIP, t.Port)
    dev := btypes.Device{
        DeviceID: t.DeviceID, Addr: *addr,
        Ip: "192.168.3.115", Port: t.Port, MaxApdu: btypes.MaxAPDU,
        ID: btypes.ObjectID{
            Type: btypes.DeviceType, Instance: btypes.ObjectInstance(t.DeviceID),
        },
    }
    rp, err := client.ReadPropertyWithTimeout(dev, btypes.PropertyData{
        Object: btypes.Object{
            ID: btypes.ObjectID{
                Type: btypes.DeviceType, Instance: btypes.ObjectInstance(t.DeviceID),
            },
            Properties: []btypes.Property{{
                Type: btypes.PropObjectName, ArrayIndex: btypes.ArrayAll,
            }},
        },
    }, 8*time.Second)
    if err == nil {
        devices[t.DeviceID] = dev
        log.Printf("✓ Device %d = %v", t.DeviceID, rp.Object.Properties[0].Data)
    }
}
```

> **关键字段**：`Addr` 由 `IPPortToAddress` 生成（6 字节 MAC: IP 4 字节 + 端口 2 字节大端序）。`MaxApdu` 建议设为 `btypes.MaxAPDU` (1476)。`ID` 字段用于 BACnet 协议层路由。

### 2.2 自动发现（补充方式）

当不知道目标端口时，用 WhoIs 单播 + 广播组合发现设备。流程很简单：

```
单播 WhoIs（向已知 IP 的默认端口 47808）→ 广播 WhoIs（同网段兜底）
```

#### 单播 WhoIs

向目标 IP 的默认 BACnet 端口 47808 发送单播 WhoIs。单播可以跨越网段，远程环境下也能工作。

```go
import (
    "github.com/anviod/bacnet"
    "github.com/anviod/bacnet/datalink"
)

// 向 192.168.3.115:47808 发单播
addr := datalink.IPPortToAddress(net.ParseIP("192.168.3.115"), 47808)
devices, _ := client.WhoIs(&bacnet.WhoIsOpts{
    Low:             0,
    High:            4194304,
    Destination:     addr,
    GlobalBroadcast: false,
})
for _, d := range devices {
    log.Printf("发现: DeviceID=%d, IP=%s, Port=%d", d.DeviceID, d.Ip, d.Port)
}
```

#### 广播 WhoIs

仅在采集端与目标设备**同一子网**时有效。跨网段/WiFi AP 环境下广播通常不工作，作为同网段兜底。

```go
devices, _ := client.WhoIs(&bacnet.WhoIsOpts{
    Low:             0,
    High:            4194304,
    GlobalBroadcast: true,
})
```

> **⚠ 远程广播限制**：跨网段、WiFi AP 环境下广播 WhoIs 可能返回 0 台。这是网络拓扑限制，非协议栈问题。此时以手动添加为主，单播为补充。

## 3. 对象扫描 (Objects)

设备添加成功后，调用 `client.Objects()` 扫描设备上所有对象及名称：

```go
scanned, err := client.Objects(dev)
if err != nil {
    log.Fatalf("扫描失败: %v", err)
}

for objType, objs := range scanned.Objects {
    if objType == btypes.DeviceType {
        continue // 跳过 Device 对象自身
    }
    for instance, obj := range objs {
        log.Printf("  %s:%d = %s", objType, instance, obj.Name)
    }
}
```

`Objects()` 内部先通过 `ObjectList` 属性获取对象列表（分片读取），再逐个获取 `ObjectName`。返回的 `Device.Objects` 按 `ObjectType -> Instance` 两级索引。

### 对象类型常量

| 常量 | 值 | 含义 |
|------|:--:|------|
| `btypes.AnalogInput` | 0 | 模拟输入（如温度传感器） |
| `btypes.AnalogOutput` | 1 | 模拟输出 |
| `btypes.AnalogValue` | 2 | 模拟值（可写设定值） |
| `btypes.BinaryInput` | 3 | 二进制输入 |
| `btypes.BinaryOutput` | 4 | 二进制输出（可写） |
| `btypes.BinaryValue` | 5 | 二进制值 |
| `btypes.DeviceType` | 8 | 设备对象 |
| `btypes.MultiStateValue` | 19 | 多状态值 |

## 4. 点位读取 (ReadProperty)

### 4.1 读取单个点位

```go
rp, err := client.ReadPropertyWithTimeout(dev, btypes.PropertyData{
    Object: btypes.Object{
        ID: btypes.ObjectID{
            Type:     btypes.AnalogInput,
            Instance: 1,
        },
        Properties: []btypes.Property{{
            Type:       btypes.PROP_PRESENT_VALUE, // 属性 ID = 85
            ArrayIndex: btypes.ArrayAll,
        }},
    },
}, 8*time.Second)

if err != nil {
    log.Printf("读取失败: %v", err)
} else if len(rp.Object.Properties) > 0 {
    log.Printf("值 = %v", rp.Object.Properties[0].Data)
}
```

### 4.2 全量遍历

```go
for objType, objs := range scanned.Objects {
    if objType == btypes.DeviceType { continue }
    for instance := range objs {
        rp, err := client.ReadPropertyWithTimeout(dev, btypes.PropertyData{
            Object: btypes.Object{
                ID: btypes.ObjectID{Type: objType, Instance: instance},
                Properties: []btypes.Property{{
                    Type: btypes.PROP_PRESENT_VALUE, ArrayIndex: btypes.ArrayAll,
                }},
            },
        }, 8*time.Second)
        if err == nil && len(rp.Object.Properties) > 0 {
            log.Printf("  %s:%d = %v", objType, instance, rp.Object.Properties[0].Data)
        }
        time.Sleep(50 * time.Millisecond) // 防止设备过载
    }
}
```

### 4.3 批量读取 (ReadMultiProperty)

```go
result, err := client.ReadMultiPropertyWithTimeout(dev, btypes.MultiplePropertyData{
    Objects: []btypes.Object{
        {
            ID: btypes.ObjectID{Type: btypes.AnalogInput, Instance: 1},
            Properties: []btypes.Property{
                {Type: btypes.PROP_PRESENT_VALUE},
                {Type: btypes.PROP_UNITS},
            },
        },
        {
            ID: btypes.ObjectID{Type: btypes.AnalogInput, Instance: 2},
            Properties: []btypes.Property{{Type: btypes.PROP_PRESENT_VALUE}},
        },
    },
}, 10*time.Second)
```

### 常用属性 ID

| 属性常量 | ID | 用途 |
|----------|:--:|------|
| `PROP_PRESENT_VALUE` | 85 | 当前值 |
| `PropObjectName` | 77 | 对象名称 |
| `PropDescription` | 28 | 对象描述 |
| `PROP_UNITS` | 117 | 工程单位 |
| `PropObjectList` | 76 | 设备对象列表 |

> **⚠ 降级策略**：部分模拟器对 ReadMultiProperty 支持不完善。批量失败时自动降级为逐个 ReadProperty，该逻辑已在 `Objects()` 中内置。

## 5. 点位写入 (WriteProperty)

### 5.1 基本写入

```go
// AnalogValue（浮点数）
err := client.WriteProperty(dev, btypes.PropertyData{
    Object: btypes.Object{
        ID: btypes.ObjectID{Type: btypes.AnalogValue, Instance: 1},
        Properties: []btypes.Property{{
            Type: btypes.PROP_PRESENT_VALUE, ArrayIndex: btypes.ArrayAll,
            Data: float32(267.0), Priority: btypes.Normal,
        }},
    },
})

// BinaryOutput（整数）
err := client.WriteProperty(dev, btypes.PropertyData{
    Object: btypes.Object{
        ID: btypes.ObjectID{Type: btypes.BinaryOutput, Instance: 1},
        Properties: []btypes.Property{{
            Type: btypes.PROP_PRESENT_VALUE, ArrayIndex: btypes.ArrayAll,
            Data: uint32(267), Priority: btypes.Normal,
        }},
    },
})
```

### 5.2 写入后二次验证

```go
func writeAndVerify(client bacnet.Client, dev btypes.Device,
    objType btypes.ObjectType, instance btypes.ObjectInstance,
    writeValue interface{}, timeout time.Duration) error {

    // Step 1: 写入
    err := client.WriteProperty(dev, btypes.PropertyData{
        Object: btypes.Object{
            ID: btypes.ObjectID{Type: objType, Instance: instance},
            Properties: []btypes.Property{{
                Type: btypes.PROP_PRESENT_VALUE, ArrayIndex: btypes.ArrayAll,
                Data: writeValue, Priority: btypes.Normal,
            }},
        },
    })
    if err != nil {
        return fmt.Errorf("写入失败: %w", err)
    }

    // Step 2: 两次读取验证（立即 + 500ms 后）
    read := func() (interface{}, error) {
        rp, e := client.ReadPropertyWithTimeout(dev, btypes.PropertyData{
            Object: btypes.Object{
                ID: btypes.ObjectID{Type: objType, Instance: instance},
                Properties: []btypes.Property{{
                    Type: btypes.PROP_PRESENT_VALUE, ArrayIndex: btypes.ArrayAll,
                }},
            },
        }, timeout)
        if e != nil || len(rp.Object.Properties) == 0 {
            return nil, e
        }
        return rp.Object.Properties[0].Data, nil
    }

    v1, _ := read()
    time.Sleep(500 * time.Millisecond)
    v2, _ := read()

    if fmt.Sprint(v1) != fmt.Sprint(v2) {
        return fmt.Errorf("值不一致: %v vs %v", v1, v2)
    }
    log.Printf("✓ 写入成功: %v", v1)
    return nil
}
```

### 5.3 只读点位处理

err := client.WriteProperty(dev, wp)

## 6. 完整示例代码

以下程序以**手动添加为主**，覆盖全流程：客户端初始化 → 手动添加设备 → 对象扫描 → 全量读取 → 可写点写入。

```go
package main

import (
    "fmt"
    "log"
    "net"
    "time"

    "github.com/anviod/bacnet"
    "github.com/anviod/bacnet/btypes"
    "github.com/anviod/bacnet/datalink"
)

func main() {
    const (
        localIP     = "192.168.3.230"   // 采集端 IP
        targetIP    = "192.168.3.115"   // 目标 IP
        readTimeout = 8 * time.Second
        clientPort  = 47815
    )

    // ═══════ Step 1: 客户端初始化 ═══════
    client, err := bacnet.NewClient(&bacnet.ClientBuilder{
        Ip: localIP, Port: clientPort, SubnetCIDR: 24, MaxPDU: btypes.MaxAPDU,
    })
    if err != nil {
        log.Fatalf("客户端创建失败: %v", err)
    }
    defer client.Close()
    go client.ClientRun()
    time.Sleep(500 * time.Millisecond)

    // ═══════ Step 2: 手动添加设备 (DeviceID + IP + Port) ═══════
    type DeviceTarget struct{ DeviceID, Port int }
    targets := []DeviceTarget{
        {1234, 47810}, {2228316, 47808}, {2228317, 60835}, {2228318, 50906},
    }

    targetIPAddr := net.ParseIP(targetIP)
    devices := make(map[int]btypes.Device)

    for _, t := range targets {
        addr := datalink.IPPortToAddress(targetIPAddr, t.Port)
        dev := btypes.Device{
            DeviceID: t.DeviceID, Addr: *addr,
            Ip: targetIP, Port: t.Port, MaxApdu: btypes.MaxAPDU,
            ID: btypes.ObjectID{Type: btypes.DeviceType, Instance: btypes.ObjectInstance(t.DeviceID)},
        }
        rp, err := client.ReadPropertyWithTimeout(dev, btypes.PropertyData{
            Object: btypes.Object{
                ID: btypes.ObjectID{Type: btypes.DeviceType, Instance: btypes.ObjectInstance(t.DeviceID)},
                Properties: []btypes.Property{{Type: btypes.PropObjectName, ArrayIndex: btypes.ArrayAll}},
            },
        }, readTimeout)
        if err == nil {
            devices[t.DeviceID] = dev
            fmt.Printf("✓ Device %d = %v\n", t.DeviceID, rp.Object.Properties[0].Data)
        }
        time.Sleep(200 * time.Millisecond)
    }

    // ═══════ Step 3: 对象扫描 ═══════
    scanned := make(map[int]btypes.Device)
    for _, t := range targets {
        dev, ok := devices[t.DeviceID]
        if !ok { continue }
        s, err := client.Objects(dev)
        if err != nil {
            fmt.Printf("✗ Device %d 扫描失败: %v\n", t.DeviceID, err)
            continue
        }
        scanned[t.DeviceID] = s
        total := 0
        for typ, objs := range s.Objects { total += len(objs) }
        fmt.Printf("✓ Device %d: %d 个对象\n", t.DeviceID, total)
        time.Sleep(200 * time.Millisecond)
    }

    // ═══════ Step 4: 全量读取 Present_Value ═══════
    for _, t := range targets {
        s, ok := scanned[t.DeviceID]
        if !ok { continue }
        dev := devices[t.DeviceID]
        for objType, objs := range s.Objects {
            if objType == btypes.DeviceType { continue }
            for instance := range objs {
                rp, err := client.ReadPropertyWithTimeout(dev, btypes.PropertyData{
                    Object: btypes.Object{
                        ID: btypes.ObjectID{Type: objType, Instance: instance},
                        Properties: []btypes.Property{{
                            Type: btypes.PROP_PRESENT_VALUE, ArrayIndex: btypes.ArrayAll,
                        }},
                    },
                }, readTimeout)
                if err == nil && len(rp.Object.Properties) > 0 {
                    fmt.Printf("  ✓ Device %d %s:%d = %v\n", t.DeviceID, objType, instance, rp.Object.Properties[0].Data)
                }
                time.Sleep(50 * time.Millisecond)
            }
        }
    }

    // ═══════ Step 5: 可写点写入 (值=267) ═══════
    writable := []btypes.ObjectType{btypes.AnalogValue, btypes.BinaryValue, btypes.BinaryOutput, btypes.AnalogOutput}
    for _, t := range targets {
        s, ok := scanned[t.DeviceID]
        if !ok { continue }
        dev := devices[t.DeviceID]
        for _, objType := range writable {
            objs, ok := s.Objects[objType]
            if !ok { continue }
            for instance := range objs {
                var val interface{}
                switch objType {
                case btypes.AnalogValue, btypes.AnalogOutput:
                    val = float32(267.0)
                default:
                    val = uint32(267)
                }
                err := client.WriteProperty(dev, btypes.PropertyData{
                    Object: btypes.Object{
                        ID: btypes.ObjectID{Type: objType, Instance: instance},
                        Properties: []btypes.Property{{
                            Type: btypes.PROP_PRESENT_VALUE, ArrayIndex: btypes.ArrayAll,
                            Data: val, Priority: btypes.Normal,
                        }},
                    },
                })
                if err != nil {
                    if err.Error() == "error class DeviceError code WriteAccessDenied" {
                        fmt.Printf("  ⚠ %s:%d 只读跳过\n", objType, instance)
                    }
                    continue
                }
                rp, _ := client.ReadPropertyWithTimeout(dev, btypes.PropertyData{
                    Object: btypes.Object{
                        ID: btypes.ObjectID{Type: objType, Instance: instance},
                        Properties: []btypes.Property{{
                            Type: btypes.PROP_PRESENT_VALUE, ArrayIndex: btypes.ArrayAll,
                        }},
                    },
                }, readTimeout)
                if len(rp.Object.Properties) > 0 {
                    fmt.Printf("  ✓ %s:%d = %v\n", objType, instance, rp.Object.Properties[0].Data)
                }
                time.Sleep(100 * time.Millisecond)
            }
        }
    }

    fmt.Println("\n✅ 采集完成")
}
```

## 7. 最佳实践

### 7.1 设备添加策略

现场工程以**手动添加**为主，确定 Device ID + IP + Port 三个关键要素后直接构造设备。端口未知时，用单播（向默认端口 47808）+ 广播组合发现。

### 7.2 客户端配置

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| `Ip` | 采集端实际 IP | 不要用 `0.0.0.0`，远程通信必须绑定具体 IP |
| `Port` | 非 47808 | 避免与目标设备端口冲突，建议 47815+ |
| `SubnetCIDR` | 24 | /24 子网 |
| `MaxPDU` | 1476 | `btypes.MaxAPDU`，避免分包 |

### 7.3 超时与重试

- **ReadProperty 超时**: 本地 3-5s，远程 8-10s
- **读取重试**: 库内置 3 次重试，带指数退避
- **写入重试**: 库内置 2 次重试
- **请求间隔**: 读取 50ms，写入 100ms，防止设备过载

### 7.4 错误处理

```go
func handleError(err error, deviceID int) bool {
    if err == nil { return true }
    switch {
    case strings.Contains(err.Error(), "timeout"):
        log.Printf("设备 %d 超时，可能离线", deviceID)
        return false
    case strings.Contains(err.Error(), "WriteAccessDenied"):
        return true // 只读点位，正常跳过
    case strings.Contains(err.Error(), "UnknownObject"):
        return true // 对象不存在，跳过
    case strings.Contains(err.Error(), "DeviceError"):
        log.Printf("设备 %d 异常: %v", deviceID, err)
        return false
    default:
        return false
    }
}
```

### 7.5 交叉编译

```bash
CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go build -o scanner .   # ARM64 网关
CGO_ENABLED=0 GOOS=linux GOARCH=arm GOARM=7 go build -o scanner .  # ARMv7
go build -o scanner.exe .  # Windows
```

### 7.6 生产环境要点

- **连接池**: 客户端线程安全，可为每个目标 IP 创建独立实例，goroutine 池并发采集
- **健康检查**: 每 30s 执行一次 `ReadProperty(Object_Name)` 作为心跳
- **状态缓存**: 缓存对象列表，设备重启后重新扫描
- **优雅退出**: 监听 SIGINT/SIGTERM，调用 `client.Close()` 释放资源

## 8. 故障排查

### 8.1 手动添加后 ReadProperty 超时

**根因**: 端口错误、设备离线、或网络不通。

**解决方案**: ping 目标 IP → 确认端口号正确 → 检查防火墙 UDP 放行。

### 8.2 广播 WhoIs 返回 0 台设备

**根因**: 广播包无法跨越网段/VLAN/WiFi AP。这是网络拓扑限制，非协议栈问题。改用单播或手动添加。

### 8.3 单播 WhoIs 返回 0 台设备

**根因**: 目标端口未运行 BACnet 设备。改为手动添加，向已知 Device ID + Port 组合直接 ReadProperty 验证。

### 8.4 ReadProperty 返回 DeviceError

**常见原因**: 端口映射错误，请求发送到了其他设备监听的端口。确认 Device ID 与端口的对应关系。

### 8.5 写入返回 WriteAccessDenied

正常现象，表示该点位为只读（如 BinaryInput、部分 BinaryValue）。捕获并跳过即可。

### 8.6 客户端端口冲突

```go
client, _ := bacnet.NewClient(&bacnet.ClientBuilder{
    Ip: "192.168.3.115", Port: 47815, SubnetCIDR: 24, // 使用非标准端口
})
```
